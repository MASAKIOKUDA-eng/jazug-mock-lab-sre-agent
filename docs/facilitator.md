# 勉強会で使うときの進め方

LT のあとに参加者に触ってもらう場合や、短いハンズオンとして使う場合のメモです。

## 時間別のおすすめ

| 使える時間 | 進め方 |
| --- | --- |
| 5 分（LT の中でデモ） | LAB 02 を Review モードで最後まで進めて見せる。対処は「B. 再起動」を選び、グラフの点線で再発することを見せると印象に残りやすい |
| 15 分 | 各自で LAB 01 → LAB 02。終わった人は LAB 02 をもう一方のモードでやり直す |
| 40 分 | 全ラボ。LAB 02 のあとに 2〜3 分、「どの対処を選んだか」を聞いてみる |

## LAB 02 で話題にしやすいところ

- **アラートの時刻と、変化が始まった時刻の違い**：アラートは 21:04 だが、メモリは 20:20 から増えている
- **「とりあえず再起動」が効かない例**：再起動を選ぶと一度は回復するが、点線で再発が見える
- **Review と Autonomous の違い**：Autonomous ではおすすめの対処が承認なしに実行される。本番で使うならどちらがよいか
- **拒否も選択肢の一つ**：拒否すると状態は悪化するが、提案に納得できないときは正しい判断になる

## よく出る質問

**Q. 実際の SRE Agent も、この画面と同じですか？**
いいえ。このラボの画面は学習用に作ったもので、実際の Azure ポータルとは違います。流れや考え方（アラート → 調査 → 提案 → 承認 → 記録）は公式ドキュメントに合わせています。

**Q. SRE Agent が間違った対処を提案したらどうなりますか？**
Review モードなら、人が拒否できます。権限やツールのアクセスポリシー、フックで「そもそもできない操作」を決めておくこともできます（LAB 03・05）。

**Q. 料金はかかりますか？**
このラボは無料です。実際の SRE Agent の料金は、Microsoft Learn の最新情報を確認してください。
