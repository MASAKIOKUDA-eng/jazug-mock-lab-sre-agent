## 利用条件

Microsoft は、これらのアイコンをアーキテクチャ図・研修資料・ドキュメントで使うことを認めています。その目的に限って、コピー・配布・表示ができます。

- アイコンの切り抜き・反転・回転・変形はしない
- アイコンの近くに製品名を書く
- Microsoft の製品アイコンを、ほかの製品やサービスを表すために使わない

公式アイコンセットには Azure SRE Agent 単体のアイコンが含まれていないため、構成図では SRE Agent を文字で表しています。GitHub、Teams、ServiceNow も Azure のアイコンセットに含まれないので、文字だけにしています。
